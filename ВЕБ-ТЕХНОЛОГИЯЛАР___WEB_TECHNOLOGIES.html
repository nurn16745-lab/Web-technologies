ВЕБ-ТЕХНОЛОГИЯЛАР

Веб-сайттарды құру, безендіру және басқару технологиялары

Веб-технологиялар — интернет желісінде ақпаратты ұсынуға, веб-сайттар мен веб-қосымшаларды құруға және олардың жұмысын қамтамасыз етуге арналған технологиялар жиынтығы. Олардың көмегімен ақпараттық ресурстар, онлайн платформалар және интерактивті қызметтер жасалады.

БӨЛІМ 01 · ҚҰРЫЛЫМ

01. HTML — веб-беттің құрылымы

01

HTML (HyperText Markup Language) — веб-беттердің құрылымын қалыптастыруға арналған гипермәтінді белгілеу тілі.

HTML веб-беттегі мәтіндерді, тақырыптарды, суреттерді, сілтемелерді, кестелерді және басқа элементтерді орналастыруға мүмкіндік береді.

HTML бағдарламалау тілі емес, белгілеу тілі болып саналады. Оның негізгі міндеті — браузерге веб-беттің мазмұны мен құрылымын түсіндіру.

HTML тілінің негізгі қызметтері:

  • Веб-беттің құрылымын қалыптастыру;
  • Тақырыптар мен мәтіндерді орналастыру;
  • Суреттер мен сілтемелерді енгізу;
  • Кестелер мен тізімдер құру;
  • Формалар арқылы пайдаланушы ақпаратын енгізу.

Негізгі HTML тегтері

Тег Қызметі
<html> HTML құжатының негізгі элементі
<head> Қызметтік ақпарат
<body> Беттің көрінетін мазмұны
<h1> Бірінші деңгейлі тақырып
<p> Мәтіндік абзац
<a> Сілтеме
<img> Сурет

HTML кодының мысалы:

index.html 
<!DOCTYPE html>
<html lang="kk">
<head>
    <meta charset="UTF-8">
    <title>Менің сайтым</title>
</head>
<body>
    <h1>Веб-технологиялар</h1>
    <p>HTML веб-беттің құрылымын жасайды.</p>
</body>
</html>

Мысал: браузерде тақырып пен мәтіннен тұратын қарапайым веб-бет пайда болады.

БӨЛІМ 02 · ДИЗАЙН

02. CSS — веб-бетті безендіру

02

CSS (Cascading Style Sheets) — веб-беттердің сыртқы көрінісін басқаруға арналған стильдер тілі.

CSS HTML арқылы құрылған элементтердің түсін, өлшемін, орналасуын, қаріп түрін және басқа да визуалды қасиеттерін өзгертуге мүмкіндік береді.

HTML веб-беттің құрылымын жасаса, CSS сол құрылымның қалай көрінетінін анықтайды.

CSS тілінің негізгі қызметтері:

  • Мәтіндердің түсі мен өлшемін өзгерту;
  • Веб-беттің фонын безендіру;
  • Элементтердің орналасуын реттеу;
  • Батырмалар мен ақпараттық блоктарды безендіру;
  • Сайтты әртүрлі экран өлшемдеріне бейімдеу.

Негізгі CSS қасиеттері

Қасиет Қызметі
color Мәтін түсі
background Фонды орнату
font-size Қаріп өлшемі
margin Сыртқы бос орын
padding Ішкі бос орын
border Шекара орнату
display Элементтің орналасу түрі

CSS кодының мысалы:

style.css 
body {
    background-color: #171717;
    color: white;
    font-family: Arial, sans-serif;
}
h1 {
    color: #c5a46d;
    text-align: center;
}
p {
    font-size: 18px;
}

Мысал: веб-беттің фоны қара түске, тақырып алтын түске өзгереді.

БӨЛІМ 03 · БАСҚАРУ

03. GitHub — жобаларды сақтау және басқару

03

GitHub — бағдарламалық жобалардың бастапқы кодын сақтауға, өзгерістерін бақылауға және басқа әзірлеушілермен бірлесіп жұмыс істеуге арналған онлайн платформа.

GitHub Git нұсқаларды басқару жүйесін пайдаланады. Ол жобадағы өзгерістер тарихын сақтауға және қажет болған жағдайда бұрынғы нұсқаларға оралуға мүмкіндік береді.

GitHub платформасының негізгі мүмкіндіктері:

  • Бағдарламалық кодтарды онлайн сақтау;
  • Жоба нұсқаларын бақылау;
  • Бірнеше адаммен бірлесіп жұмыс істеу;
  • Жобаға енгізілген өзгерістерді тіркеу;
  • Дайын веб-сайттарды GitHub Pages арқылы жариялау.

GitHub-та қолданылатын негізгі ұғымдар

Ұғым Түсіндірмесі
Repository Жоба файлдары сақталатын репозиторий
Commit Өзгерістерді тіркеу
Branch Жобаның жеке тармағы
Pull Request Өзгерістерді негізгі жобаға біріктіруді ұсыну
GitHub Pages Статикалық сайттарды жариялау қызметі
